# ADR-0005：有界密集 SVD 与局部秩诊断

- 状态：已采纳，回溯记录
- 记录日期：2026-10-13
- 决策范围：3D 求解步骤、线性代数、DOF 与冗余

## 背景

装配残差行存在天然线性相关，秩亏是正常模型状态。正规方程会平方条件数，求解步、秩和冗余若使用不同尺度或阈值，容易互相矛盾。

平移与旋转导数的量纲及大小不同。大锚点会放大旋转列，用全局阈值直接截断原始雅可比会把平移方向误判为零。

## 决策

- 3D 采用自有 LM 控制循环、解析局部雅可比和 `nalgebra` 密集 SVD 阻尼伪逆；核心控制接受步、容差和迭代语义。
- 每次 LM 外层迭代最多尝试 8 次阻尼步；外层受 `max_iterations` 限制，驻点尝试有界确定性逃逸。
- 所有 SVD 调用使用非零 **4096** 内部迭代预算，分解精度参数为 `5 * f64::EPSILON`。预算耗尽显式返回错误，不使用库中表示无限迭代的零预算。
- 检查矩阵尺寸、输入和分解结果的有限性；不可可靠分析时返回当前契约的 `invalid_model`，不捏造秩。
- 平移列和旋转列分别按三元组的最大绝对元素做尺度均衡。同一三维向量的三个分量共享尺度，零三元组使用 1。
- LM 在均衡矩阵上求步，再按列尺度还原；秩和 condition 使用终态同一均衡局部雅可比。
- 数值非零奇异值阈值为 `σ_i > σ_max * 1e-10`。3D 剩余 DOF 为自由参数数减该局部秩。
- 3D 满足位形的冗余判断通过删去整个约束块后秩是否变化，并按重叠贡献分组；子集沿用完整矩阵的均衡尺度与秩阈值，不按书写顺序贪心判定。
- 重复 `fixed` 直接报告；其余局部冗余分析限定在收敛位形。

当前是密集后端。约束图分解、缓存与稀疏分解均是未来工作。2D 点到原点距离仍走闭式路径，零目标按几何解集给出 0 DOF。

## 考虑的替代方案

| 方案 | 未采用或延后的原因 |
|---|---|
| 正规方程配合直接分解 | 秩亏和病态时放大数值问题，不能直接提供所需谱诊断 |
| 未均衡矩阵的全局阈值 | 混合单位和大锚点容易造成错误秩 |
| 每一列独立归一 | 可能放大近乎无约束的单轴方向，改变三维向量内的度量 |
| 立即替换稀疏后端 | 尚需规模证据、确定性排序和同语义回归；列入路线图 |

## 影响与代价

- DOF 是返回位形的一阶信息，不能等同于任意奇异机构的真实非线性运动维数。
- 冗余是在该位形的线性化中不增加秩；不证明删除约束保持全局解集，建议删除后必须重新验证。
- condition 是均衡矩阵的非零谱条件数，不能解读为原始物理单位下的条件数。
- 重复密集 SVD 成本随规模增长；内部迭代预算只保证分解有界，不提供整体墙钟时间或内存上限。
- 固定阈值与尺度规则属于数值行为；修改会影响 DOF、冗余和 parity。

## 重新评估条件

真实模型暴露误判秩、尺度依赖或诊断延迟超预算时，复查阈值与分解策略。新增后端必须维持契约含义、明确奇异边界，并提供独立几何检查、规模数据及跨平台确定性证据。
