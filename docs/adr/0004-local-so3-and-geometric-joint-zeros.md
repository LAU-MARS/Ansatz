# ADR-0004：局部 SO(3) 增量与几何关节零位

- 状态：已采纳，回溯记录
- 记录日期：2026-10-13
- 决策范围：3D 位姿优化、关节变量、回灌行为

## 背景

外部位姿使用 rotation vector `v = θ·û`，便于 JSON 表达三个旋转分量。但这个表示不全局唯一，直接对全局向量相加、求导会把 `2π` 处的坐标奇异带入 DOF 诊断。

若关节零位取自每次输入姿态，则驱动值不再是绝对几何量：回灌求解结果会重置零位，导致重复求解继续移动。

## 决策

- JSON 存储保持 rotation vector，避免本次修复改变外部位姿契约。
- 每个自由刚体使用三个平移增量和三个局部旋转增量；旋转更新为 `R_new = R · exp([δ]×)`。
- `so3::retract` 通过四元数复合实现局部更新，再返回 rotation vector；零增量保留原输入 bits。
- 雅可比使用局部 SO(3) 切空间，不对全局 rotation vector 图表直接求导。DOF 不应继承 `2π` 表示的坐标退化。
- 转动副角度从两体本地参考方向的世界变换测量；显式参考方向投影到轴法平面再归一。缺省参考方向由本地轴确定性生成。
- 移动副位移是两轴原点的有向轴向距离；`drive` 是绝对目标。移动副 `a_ref`、`b_ref`、`roll` 必须同时提供或同时缺省；全部缺省时仍锁定确定性零滚转。
- 转动目标通过有界取模折回，禁止逐次减去 `2π` 的无界循环。传动差值也按周期处理。
- `Angle` 先归一方向，并按实际弧度误差判断满足；精确 `0` 和 `π` 使用两维方向对齐语义。Coaxial 及轴关节要求同向。

关节角使用主值 `(−π, π]`。连续展开角、传动累计相位和分支追踪尚未实现；当前无状态输入不能恢复跨越多个周期的运动历史。

## 考虑的替代方案

| 方案 | 未采用或延后的原因 |
|---|---|
| 对全局 rotation vector 直接加步长 | 坐标奇异会污染雅可比与 DOF，几何等价表示产生不同诊断 |
| 外部立即迁移四元数 | 局部增量已能解决当前问题；迁移会改变 JSON 契约 |
| 以输入姿态定义关节零位 | 驱动含义随调用改变，破坏绝对目标和回灌幂等 |
| 用无向叉积独自表达同轴 | 正向与反向都得到零残差，不能实现同向契约 |

四元数存储也可以配合三个局部优化变量，不必新增单位范数方程；这属于可能的后续存储方案。

## 影响与代价

- 表示等价应给出一致的局部秩行为；实体数值表示本身仍可不同。
- 非零旋转更新可能返回另一个 rotation vector 分支；不能据此承诺连续显示角度。
- 默认参考方向是模型语义的一部分，今后改变选择规则会改变关节零位。
- 有限的大目标可以有界处理，但输入已丢失的周期精度无法靠取模恢复。
- 位姿、方向对齐和关节测量需要共同验证，单独检查残差下降不够。

## 重新评估条件

支持连续拖拽、展开角、多圈传动、明确装配分支或四元数存储时，需要新的状态与兼容性设计。其零位必须仍由显式几何定义，并继续验证 parity 与实体回灌幂等。
